# OBS Overlay: план

## Архитектура

- SvelteKit на `@sveltejs/adapter-node`, один Node-процесс.
- `hooks.server.ts` — корень приложения: создаёт состояние игры, стартует
  чат-бот (twurple). Гард — корень инициализируется один раз.
- `src/routes/api/overlay/sse/+server.ts` — SSE-эндпоинт, отдаёт кадры снапшота
  оверлея.
- Запуск: `pnpm dev` (полный стек), прод — `pnpm build && node build`, порт из
  `.env`. `pnpm bot` — только чат без веб-сервера, в оверлее не участвует.

## Игровые механики

- `!join` удаляется из парсера и replies.
- Заказы появляются во входящих (3 слота) автоматически; интервалы появления и
  время жизни невзятого заказа настраиваются в `config`.
- `!взять N` — игрок берёт заказ из слота; сессия и персонаж создаются лениво; у
  игрока один активный заказ.
- Заказ собирается по блюдам: игрок готовит текущий MenuItem, `!next`
  запечатывает снятые слои и очищает поднос для следующего блюда. `!serve`
  отдаёт весь заказ целиком (запечатанные блюда + текущее), после оценки + XP
  игрок снова свободен для `!взять`.
- Время на заказ — таймер (настраивается в `config`), оценка и XP — через
  `OrderValidator`/`scoring`.
- `!заказ` — напоминание состава своего заказа (выводится на мониторе
  исполнения, см. ниже) — отдельная команда, не связана со взятием.
- `!рецепт <блюдо>` — отобразить рецепт на окне рецептов; неизвестное блюдо —
  «нет такого блюда».
- `!put`, `!bin`, `!menu` — без изменений.
- Команды: `!взять`/`!take <1|2|3>`, `!заказ`/`!order`, `!next`,
  `!рецепт`/`!recipe <блюдо>`.
- Ответы-отказы: «слот пуст», «у тебя уже есть заказ», «нет активного заказа»,
  «это было последнее блюдо заказа», «нет такого блюда».

## Мониторы

- Входящие — монитор из 3 слотов: заказы, ожидающие взятия.
- Исполнения — монитор из 3 фиксированных слотов: карточка показывает
  «исполнитель» и состав заказа (MenuItem). По `!заказ` карточка своего заказа
  занимает слот по FIFO (перезапись старейшего); позиции слотов не меняются.
- Рецепты — отдельное окно с одним рецептом.

## Снапшот оверлея (состав)

- Сцена: станции (полки с ингредиентами, мусорка, выдача, терминал рецептов) и
  персонажи (позиция, поднос, заказ).
- Заказ игрока над головой — **MenuItem**: пустой силуэт для неготового блюда,
  заполненный — для запечатанного, текущее подсвечивается.
- Доски: входящие (3 слота), исполнения (3 слота), рецепт (1 окно).

## Фронт

- `pixi.js` v8 + Svelte 5, один `<canvas>`, обвязка на Svelte.
- `src/routes/overlay/+page.svelte` — один canvas для всего: сцена (кухня,
  персонажи), мониторы (входящие, исполнения), окно рецепта.
- `src/lib/overlay/overlay-store.ts` — `EventSource("/api/overlay/sse")` →
  store.
- `src/lib/overlay/pixi-scene.ts`, `src/lib/overlay/pixi-boards.ts` — сцена и
  мониторы, рисунок из снапшота.
- `src/lib/overlay/loader.ts` — загрузка ассетов по манифесту.

## Ассеты

- `static/assets/manifest.json` — список ресурсов (Pixi `Assets`).
- `static/assets/ingredients/<id>.png` — иконки ингредиентов / простых
  предметов.
- `static/assets/stations/<kind>.png` — полка, мусорка, выдача, терминал.
- `static/assets/characters/base.png` — спрайт персонажа.
- `static/assets/boards/frame.png` — рамка слота монитора.
- Отсутствующий в манифесте ассет не рисуется (пустые слоты, без заглушек).
- Тень над головой — тот же спрайт с серым tint.
