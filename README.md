# Twitch Cafe

Игра для чата Twitch: зрители превращаются в поваров кафе, берут заказы с доски,
собирают блюда из ингредиентов и отдают их клиентам. Всё происходит прямо в чате
— писать ничего не нужно заранее, достаточно знать команды.

Клиенты бывают придирчивыми: одному простительно всё, другому нужен идеальный
бургер со слоями в правильном порядке. Оценка заказа приносит или отнимает XP.

## Игровой цикл

1. **Заказы появляются на доске входящих.** Их три слота, заказ лежит в слоте
   ограниченное время — не взял, и он «сгорает».
2. **Берёшь заказ:** `!взять 1` (номер слота — от 1 до 3). Одновременно у одного
   игрока может быть только один активный заказ.
3. **Носишь ингредиенты на поднос:** `!put котлета`. Слои кладутся в том
   порядке, в котором ты пишешь команды, — порядок важен для многих блюд.
4. **Если в заказе несколько блюд**, каждое блюдо собирается отдельно, а готовое
   «запечатывается» командой `!next`. После этого поднос чист, и можно собирать
   следующее блюдо.
5. **Сдаёшь заказ:** `!serve`. Клиент оценивает сборку, ты получаешь вердикт и
   XP.

## Команды

| Команда             | Алиасы             | Что делает                                      |
| ------------------- | ------------------ | ----------------------------------------------- |
| `!взять <1-3>`      | `!take <1-3>`      | взять заказ из слота доски входящих             |
| `!put <ингредиент>` | `!add`, `!положи`  | положить ингредиент на поднос                   |
| `!next`             | —                  | запечатать текущее блюдо и очистить поднос      |
| `!serve`            | `!submit`          | отдать весь заказ на проверку                   |
| `!bin`              | —                  | выбросить содержимое подноса в мусорку          |
| `!menu`             | `!заказ`, `!order` | напомнить свой заказ и что уже лежит на подносе |
| `!рецепт <блюдо>`   | `!recipe <блюдо>`  | показать рецепт блюда на доске рецептов         |

Ингредиент в `!put` можно писать целиком («котлета») или куском названия («сыр»,
«верхняя») — регистр не важен. Название блюда в `!рецепт` работает так же:
`!рецепт бургер`.

## Как собирать блюда

**Бургер** — слои кладутся снизу вверх, порядок начинки важен:

```txt
!put нижняя булочка
!put котлета
!put сыр
!put верхняя булочка
```

**Кола** — простой предмет, достаточно положить его на поднос: `!put кола`.

## Оценка и опыт

Что оценивает клиент:

- **не хватает** ингредиента — штраф;
- **лишнее** на подносе — штраф;
- **порядок начинки нарушен** — штраф для блюд с фиксированным порядком (бургер,
  хот-дог);
- **база не на своём месте** — булки, тесто и прочая основа должны быть
  снизу/сверху, а не в середине; за это штраф больше всего;
- **не то блюдо** — клиент в недоумении, оценка нулевая.

Вердикты по итоговой оценке заказа:

| Вердикт       | Когда                |
| ------------- | -------------------- |
| **Идеально!** | почти без отклонений |
| **Хорошо!**   | мелкие огрехи        |
| **Неплохо.**  | заметные ошибки      |
| **Плохо…**    | много нарушений      |
| **Ужасно!**   | всё сделано не так   |

XP считается симметрично: идеальный заказ приносит опыт, полностью проваленный
отнимает столько же, а сборка «на половину» оставляет около нуля. Если не успеть
отдать заказ вовремя, он сгорает и это стоит опыта — не тяни с подачей.

## Клиенты

У каждого заказа свой клиент, и у него своя **придирчивость** — насколько сильно
его задевают отклонения от идеальной сборки:

| Клиент       | Придирчивость | Что прощает                                   |
| ------------ | ------------- | --------------------------------------------- |
| **Голодный** | низкая        | почти всё: съест даже с булкой не на месте    |
| **Обычный**  | средняя       | мелкие вольности, но грубые нарушения заметит |
| **Гурман**   | высокая       | ничего: нужен идеальный состав и порядок      |

Чем придирчивее клиент, тем дороже любая ошибка в XP.

## Тайминги заказов

- Заказы появляются на доске входящих сами — в первый свободный слот.
- У невзятого заказа есть срок жизни: не успел его взять — заказ сгорает, а слот
  освобождается под следующий.
- На выполнение взятого заказа тоже даётся ограниченное время: не успел отдать
  заказ до дедлайна — он сгорает, и игрок теряет опыт.
- Точные интервалы и лимиты времени подбираются по балансу игры. Ориентируйся на
  таймеры «осталось» на мониторах оверлея.

## Оверлей для стрима

Игра рисует картинку для трансляции: кухню со станциями (полки с ингредиентами,
мусорка, выдача, терминал рецептов) и мониторы:

- **Входящие** — три слота с заказами, которые ждут исполнителя;
- **Исполнение** — три слота с тем, кто взял заказ и что уже готово (готовые
  блюда отмечаются галочкой);
- **Рецепт** — окно, куда выводится рецепт по команде `!рецепт`.

Оверлей только показывает состояние игры и поверх него удобно ложится сцена с
геймплеем — команды, заказы и оценки живут в чате.

## Production и OBS

Скопируй `.env.example` в `.env` и заполни Twitch-переменные. Без полного набора
credentials сервер намеренно завершает запуск с ошибкой.

```bash
pnpm build
HOST=0.0.0.0 PORT=4311 pnpm start
```

В OBS нужен один Browser Source на `http://127.0.0.1:4311/`: размер `1920x1080`,
30 FPS, прозрачный фон. Для удалённого OBS используй IP этой машины вместо
`127.0.0.1`.
